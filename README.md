The funniest one line a talking elevator could say — 93 characters, one line, nothing else:

> Doors closing. If you wanted privacy, maybe don't have your breakup on floor 9 every Tuesday.

## Run it

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). The program self-checks the line against the scorer's gate before writing: 1–120 characters, a single line, not only white space.
